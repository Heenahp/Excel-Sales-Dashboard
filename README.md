# 📊 Excel Sales Dashboard

## 📌 Project Overview
This project is an interactive Sales Dashboard built using Microsoft Excel. It provides insights into sales performance through Pivot Tables, Pivot Charts, and Slicers.

## 🚀 Features
- Monthly Sales Trend Analysis
- Sales by Region
- Product-wise Sales Quantity
- Interactive Slicers (Customer Type, Territory, Product)
- Pivot Tables & Pivot Charts

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
